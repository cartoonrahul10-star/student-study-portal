📐 Unit 1 – Matrix Algebra

Important concepts, formulas and methods

1. Matrix

A matrix is a rectangular arrangement of numbers in rows and columns.

Order of matrix: m × n

where m = number of rows and n = number of columns.

2. Rank of a Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns.

Important:

Rank(A) = number of non-zero rows in echelon form.

For a matrix of order m × n:

Rank(A) ≤ min(m, n)

3. System of Linear Equations

General form:

a₁x + b₁y + c₁z = d₁

a₂x + b₂y + c₂z = d₂

a₃x + b₃y + c₃z = d₃

For AX = B:

Consistent system: Rank(A) = Rank([A|B])

Unique solution: Rank(A) = Rank([A|B]) = number of unknowns.

Infinite solutions: Rank(A) = Rank([A|B]) < number of unknowns.

No solution: Rank(A) ≠ Rank([A|B]).

4. Eigenvalues

For a square matrix A, eigenvalues are obtained from:

|A − λI| = 0

where λ is an eigenvalue and I is the identity matrix.

5. Eigenvectors

For each eigenvalue λ, the corresponding eigenvector X is obtained from:

(A − λI)X = 0

6. Important Properties of Eigenvalues

• Sum of eigenvalues = Trace of matrix

• Product of eigenvalues = Determinant of matrix

• Eigenvalues of identity matrix = 1

• If A is triangular, its eigenvalues are its diagonal elements.

7. Cayley-Hamilton Theorem

Every square matrix satisfies its own characteristic equation.

If the characteristic equation is:

λⁿ + a₁λⁿ⁻¹ + a₂λⁿ⁻² + ... + aₙ = 0

Then the matrix satisfies:

Aⁿ + a₁Aⁿ⁻¹ + a₂Aⁿ⁻² + ... + aₙI = 0

8. Diagonalization of Matrix

A matrix A is diagonalizable if:

A = PDP⁻¹

where:

• P = matrix of eigenvectors

• D = diagonal matrix of eigenvalues

• P⁻¹ = inverse of P

9. Characteristic Equation

The characteristic equation of matrix A is:

|A − λI| = 0

The roots of this equation are the eigenvalues of A.

⭐ Exam Important Formulas

1. |A − λI| = 0

2. (A − λI)X = 0

3. Sum of eigenvalues = Trace(A)

4. Product of eigenvalues = |A|

5. A = PDP⁻¹

6. Rank(A) = number of non-zero rows in echelon form

7. Rank(A) = Rank([A|B]) → consistent system

📝 Solved Examples – Unit 1

Example 1: Rank of a Matrix

Consider:

A = [ 1 2 3 ]
    [ 2 4 6 ]
    [ 1 1 1 ]

Using elementary row operations, the matrix can be reduced to echelon form.

Number of non-zero rows = 2

Therefore, Rank(A) = 2.

Example 2: Eigenvalues

For a square matrix A, eigenvalues are obtained from:

|A − λI| = 0

First form the characteristic equation and solve it for λ.

The roots obtained are the eigenvalues of A.

Example 3: Eigenvector

After finding an eigenvalue λ, the corresponding eigenvector X is obtained from:

(A − λI)X = 0

Solve these simultaneous equations to obtain the eigenvector.

Example 4: Cayley-Hamilton Theorem

If the characteristic equation of A is:

λ² − 5λ + 6 = 0

According to Cayley-Hamilton theorem:

A² − 5A + 6I = 0

Hence, the matrix A satisfies its own characteristic equation.

📘 Unit 2 – Multivariable Calculus

Important concepts and formulas

1. Function of Two Variables

A function of two variables is written as:

z = f(x, y)

2. Limit and Continuity

The limit of f(x,y) as (x,y) approaches (a,b) is written as:

lim f(x,y) = L

For continuity at (a,b):

lim f(x,y) = f(a,b)

3. Partial Derivatives

If z = f(x,y), then:

∂z/∂x → differentiate with respect to x, keeping y constant.

∂z/∂y → differentiate with respect to y, keeping x constant.

4. Euler's Theorem

If z is a homogeneous function of degree n:

x(∂z/∂x) + y(∂z/∂y) = nz

5. Chain Rule

If z = f(x,y), where x and y depend on t:

dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)

6. Total Derivative

For z = f(x,y):

dz = (∂z/∂x)dx + (∂z/∂y)dy

7. Jacobian

The Jacobian of u,v with respect to x,y is:

∂(u,v)/∂(x,y)

= | ∂u/∂x   ∂u/∂y |

  | ∂v/∂x   ∂v/∂y |

8. Taylor's Theorem

For a function of two variables:

f(x+h,y+k) can be expanded using partial derivatives of f.

Important terms include first, second and higher-order partial derivatives.

9. Maxima and Minima

For f(x,y), first find:

fₓ = 0 and fᵧ = 0

Let:

A = fₓₓ, B = fₓᵧ, C = fᵧᵧ

Then:

D = AC − B²

If D > 0 and A > 0 → Local minimum.

If D > 0 and A < 0 → Local maximum.

If D < 0 → Saddle point.

10. Lagrange's Method

For finding maximum or minimum subject to a constraint:

∇f = λ∇g

where λ is the Lagrange multiplier.

11. Double Integral

Double integral is written as:

∫∫ f(x,y) dx dy

It is commonly used to calculate area and volume-related quantities.

12. Triple Integral

Triple integral is written as:

∫∫∫ f(x,y,z) dx dy dz

It is commonly used for volume and three-dimensional quantities.

⭐ Unit 2 Important Formulas

1. z = f(x,y)

2. dz = zₓdx + zᵧdy

3. xzₓ + yzᵧ = nz

4. dz/dt = zₓ(dx/dt) + zᵧ(dy/dt)

5. D = AC − B²

6. ∇f = λ∇g

📊 Unit 3 – Fourier Series

Important concepts, formulas and exam points

1. Fourier Series

A periodic function can be represented as an infinite series of sine and cosine functions.

General Fourier Series:

f(x) = a₀/2 + Σ [aₙ cos(nx) + bₙ sin(nx)]

2. Fourier Coefficients

Constant term:

a₀ = (1/π) ∫₋π^π f(x) dx

Cosine coefficient:

aₙ = (1/π) ∫₋π^π f(x) cos(nx) dx

Sine coefficient:

bₙ = (1/π) ∫₋π^π f(x) sin(nx) dx

3. Convergence of Fourier Series

For a suitable periodic function, the Fourier series converges to the value of the function at points of continuity.

At a discontinuity, it converges to the average of the left-hand and right-hand limits:

[f(x⁺) + f(x⁻)] / 2

4. Even Function

A function is even if:

f(−x) = f(x)

For an even function:

bₙ = 0

Therefore, the Fourier series contains only cosine terms.

5. Odd Function

A function is odd if:

f(−x) = −f(x)

For an odd function:

a₀ = 0 and aₙ = 0

Therefore, the Fourier series contains only sine terms.

6. Half-Range Fourier Series

When a function is defined only over half of its usual interval, we can represent it using a half-range Fourier series.

Half-range sine series:

bₙ = (2/L) ∫₀ᴸ f(x) sin(nπx/L) dx

Half-range cosine series:

aₙ = (2/L) ∫₀ᴸ f(x) cos(nπx/L) dx

7. Important Points

• Periodic function repeats itself after a fixed interval.

• Even function gives cosine series.

• Odd function gives sine series.

• Half-range expansion can be sine or cosine type.

• Fourier coefficients are calculated using integration.

⭐ Unit 3 Important Formulas

1. f(x) = a₀/2 + Σ[aₙcos(nx) + bₙsin(nx)]

2. a₀ = (1/π)∫₋π^π f(x)dx

3. aₙ = (1/π)∫₋π^π f(x)cos(nx)dx

4. bₙ = (1/π)∫₋π^π f(x)sin(nx)dx

5. Even function → bₙ = 0

6. Odd function → a₀ = aₙ = 0

🧭 Unit 4 – Vector Calculus

Important concepts, formulas and theorems

1. Gradient

For a scalar function φ(x,y,z), the gradient is:

∇φ = i(∂φ/∂x) + j(∂φ/∂y) + k(∂φ/∂z)

The gradient points in the direction of maximum increase of the scalar function.

2. Divergence

For a vector field F = Pi + Qj + Rk:

∇·F = ∂P/∂x + ∂Q/∂y + ∂R/∂z

If ∇·F = 0, the vector field is called solenoidal.

3. Curl

For F = Pi + Qj + Rk:

∇×F = curl F

It represents the rotational nature of a vector field.

4. Directional Derivative

The directional derivative of φ in the direction of unit vector â is:

Dₐφ = ∇φ · â

5. Important Vector Identities

∇·(∇φ) = ∇²φ

∇×(∇φ) = 0

∇·(∇×F) = 0

Here ∇²φ is called the Laplacian of φ.

6. Line Integral

The line integral of a vector field F along a curve C is:

∫C F · dr

7. Surface Integral

The surface integral of a vector field F over a surface S is:

∫S F · n̂ dS

8. Volume Integral

A volume integral over a region V is written as:

∫V f dV

9. Gauss Divergence Theorem

The total outward flux through a closed surface is related to the volume integral of divergence:

∫S F · n̂ dS = ∫V (∇·F) dV

10. Stokes' Theorem

Stokes' theorem relates a line integral around a closed curve to a surface integral of curl:

∮C F · dr = ∫S (∇×F) · n̂ dS

11. Green's Theorem

For a positively oriented closed curve C enclosing a region R:

∮C (P dx + Q dy)

= ∬R (∂Q/∂x − ∂P/∂y) dA

⭐ Unit 4 Important Formulas

1. ∇φ = iφₓ + jφᵧ + kφᵧ

2. ∇·F = Pₓ + Qᵧ + Rᵤ

3. Dₐφ = ∇φ · â

4. ∇×(∇φ) = 0

5. ∇·(∇×F) = 0

6. Gauss: ∫SF·n̂dS = ∫V∇·F dV

7. Stokes: ∮CF·dr = ∫S(∇×F)·n̂dS

📘 Unit 5 – Ordinary Differential Equations

Important concepts, formulas and methods

1. Differential Equation

A differential equation is an equation involving a dependent variable and its derivatives.

Order: The highest order derivative present in the equation.

Degree: The power of the highest order derivative, when the equation is polynomial in derivatives.

2. First Order Differential Equation

A first-order differential equation can be written as:

dy/dx = f(x,y)

3. Variable Separable Equation

If an equation can be written as:

g(y)dy = f(x)dx

Then integrate both sides:

∫g(y)dy = ∫f(x)dx + C

4. Linear Differential Equation

Standard form:

dy/dx + Py = Q

Integrating Factor (I.F.):

I.F. = e∫P dx

Solution:

y × I.F. = ∫(Q × I.F.)dx + C

5. Bernoulli's Equation

Standard form:

dy/dx + Py = Qyn

Put:

v = y1−n

After substitution, the equation becomes a linear differential equation in v.

6. Exact Differential Equation

For:

M dx + N dy = 0

The equation is exact if:

∂M/∂y = ∂N/∂x

7. First Order Nonlinear Equations

Nonlinear first-order differential equations may be solved using suitable substitutions or standard methods depending on their form.

8. Higher Order Linear Differential Equation

A general linear differential equation is:

aₙ dⁿy/dxⁿ + ... + a₁dy/dx + a₀y = X

It can be represented using the differential operator D:

F(D)y = X

9. Complementary Function (C.F.)

For the homogeneous equation:

F(D)y = 0

The solution obtained from the auxiliary equation is called the complementary function.

10. Particular Integral (P.I.)

For:

F(D)y = X

The particular solution corresponding to X is called the particular integral.

Complete solution:

y = C.F. + P.I.

⭐ Unit 5 Important Formulas

1. dy/dx = f(x,y)

2. I.F. = e∫P dx

3. y × I.F. = ∫(Q × I.F.)dx + C

4. Bernoulli: dy/dx + Py = Qyn

5. Exact equation: Mdx + Ndy = 0

6. Exact condition: ∂M/∂y = ∂N/∂x

7. F(D)y = X

8. Complete solution = C.F. + P.I.
